*agents.nvim*                     Provider-neutral coding agents in Neovim

==============================================================================
INTRODUCTION                                                     *agents-intro*

agents.nvim runs a coding-agent CLI in a Neovim terminal while leaving session
persistence with the native provider. Supported providers are Claude Code and
Codex CLI.

==============================================================================
SETUP                                                               *agents-setup*

>lua
  require("agents").setup({
    default_provider = "claude",
    cwd = nil,
    close_on_exit = true,
    window = { position = "right", size = 0.4 },
    mappings = {
      prefix = "<C-f>",
      toggle = "<prefix>",
      escape = "f",
      context = "p",
      changes = "d",
      next_change = "dj",
      previous_change = "dk",
      next = "l",
      previous = "h",
    },
    refresh = {
      enabled = true,
      events = { "BufEnter", "FocusGained", "CursorHold" },
    },
    suggestions = {
      enabled = false,
      provider = "claude",
      context_lines = 100,
      max_context_bytes = 64 * 1024,
      timeout_ms = 30 * 1000,
      mappings = {
        request = "<C-f>s",
        accept = "<C-f>a",
        dismiss = "<C-f>x",
      },
    },
    providers = {
      claude = { command = "claude", args = {} },
      codex = { command = "codex", args = {} },
    },
  })
<

Each mapping joins mappings.prefix with its action suffix. The special
"<prefix>" suffix means the prefix itself, so the default toggle is
<C-f><C-f>. The toggle mapping shows or hides the agent window without
stopping its job. It works from Normal mode and the agent terminal. The escape
mapping is local to the agent terminal and enters Terminal-Normal mode; press
|i| to return to Terminal mode. The context mapping works in Visual mode.
Change review and session navigation work in Normal mode. Their defaults are
<C-f>d, <C-f>dj, <C-f>dk, <C-f>l, and <C-f>h, respectively. Set an action to
false to disable it.

Each open, resume, or continue action creates a new plugin session. Sessions
share one sidebar and remain running when hidden. The sidebar winbar displays
clickable session labels in the form {id}:{provider}; an x marks a stopped or
exited session. When close_on_exit is true, a natural exit from the active CLI
hides the sidebar but retains the terminal transcript.

Buffer refresh uses Neovim's external-change check on the configured events.
FocusGained checks all loaded file buffers; BufEnter and CursorHold check the
event buffer. Modified, unnamed, unloaded, and non-file buffers are skipped, so
unsaved contents are not replaced. Set refresh.enabled to false or use an empty
events list to install no refresh autocommands. Supported events are BufEnter,
FocusGained, and CursorHold. This implementation is event-driven and does not
install a filesystem watcher.

Each session started inside a Git worktree captures the visible workspace as a
private baseline before its agent process launches. This does not modify the
real Git index or working files. Change review is explicitly requested because
native terminal providers do not expose a reliable prompt-completion event.

Inline suggestions are experimental and disabled by default. Their mappings are
complete Normal-mode key sequences and do not use mappings.prefix. When enabled,
<C-f>s requests a suggestion, <C-f>a accepts it, and <C-f>x dismisses it.
Set any suggestion mapping to false to disable it.

==============================================================================
COMMANDS                                                         *agents-commands*

                                                   *:Agents-open*
:Agents open [provider]
    Start and select a new session with the provider.

                                                   *:Agents-resume*
:Agents resume [provider] [session-id]
    Resume a session. Omitting the ID opens the provider's native picker. An
    unrecognized second argument is treated as an ID for the default provider.

                                                   *:Agents-continue*
:Agents continue [provider]
    Continue the most recent conversation for the current directory.

                                                   *:Agents-toggle*
:Agents toggle
    Show or hide the agent sidebar without stopping any session.

                                                   *:Agents-next*
:Agents next
    Select the next session, wrapping at the end.

                                                   *:Agents-prev*
:Agents prev
    Select the previous session, wrapping at the beginning.

                                                   *:Agents-select*
:Agents select [session-id]
    Select a plugin session. Omitting the ID opens a picker.

                                                   *:Agents-context*
:'<,'>Agents context
    Paste the current characterwise or linewise Visual selection into the
    active running chat as a file path and range, without submitting it. The
    file must be saved. Blockwise selections are not supported. After the
    reference is inserted, the sidebar is focused in Terminal mode. Claude
    references use an @ prefix; Codex references use the plain path.

                                                   *:Agents-changes*
:Agents changes [session-id]
    List Git workspace files that currently differ from the selected session's
    baseline. Selecting a file opens the read-only baseline beside the editable
    current file in a diff tab. The active session is used when the ID is
    omitted. Pre-existing edits are excluded unless they change again.

                                                   *:Agents-next-change*
:Agents next-change
    Review the next file in the captured change list, wrapping at the end.

                                                   *:Agents-prev-change*
:Agents prev-change
    Review the previous file in the captured change list, wrapping at the
    beginning. Use |[c| and |]c| to move between hunks within a file.

                                                   *:Agents-reset-changes*
:Agents reset-changes [session-id]
    Capture the current Git workspace as the selected session's new baseline.
    This invalidates its current navigation list without changing the Git index.

                                                   *:Agents-suggest*
:Agents suggest
    Ask the configured suggestion provider for text to insert at the current
    byte boundary. The current implementation supports Claude Code only. The
    preview is ghost text and does not modify the buffer.

                                                   *:Agents-suggest-accept*
:Agents suggest-accept
    Insert the visible suggestion as one undoable edit. The insertion boundary
    is immediately before the character under the captured Normal-mode cursor;
    no character or selection is replaced.

                                                   *:Agents-suggest-dismiss*
:Agents suggest-dismiss
    Cancel the pending request or clear its ghost text. This is a quiet no-op
    when no suggestion exists.

                                                   *:Agents-stop*
:Agents stop [session-id]
    Stop a session while retaining its terminal transcript. The active session
    is used when the ID is omitted.

                                                   *:Agents-close*
:Agents close [session-id]
    Stop and remove a session and its terminal buffer. The active session is
    used when the ID is omitted.

                                                   *:Agents-health*
:Agents health
    Report whether configured providers are executable and, when inline
    suggestions are enabled, whether their configured provider is available.

The context operation is also available as require("agents").context(). It is
intended for Visual-mode mappings.

Change review is also available through require("agents").changes(id),
next_change(), previous_change(), and reset_changes(id). It represents current
workspace differences since the plugin session baseline; concurrent edits by
the user or another process cannot be conclusively attributed to the agent.
Ignored files and submodule-internal worktree changes are outside version-one
tracking. Sessions still open outside Git, but their change command reports the
tracking error.

Inline suggestions are also available through require("agents").suggest(),
accept_suggestion(), and dismiss_suggestion(). They require a named, loaded,
modifiable file buffer. Unsaved contents are authoritative. A request includes
the absolute path, filetype, cursor line, and capped nearby source context and
therefore may incur provider cost and disclose source code to Claude. Each
request uses a fresh asynchronous process with tools and session persistence
disabled. Moving the cursor, editing, entering Insert mode, leaving the buffer,
or starting another request cancels or clears the suggestion. Continuous
completion, selection replacement, and providers other than Claude are not
supported.

==============================================================================
PROVIDERS                                                       *agents-providers*

A provider implements is_available(config), supports(action), and
build_command(action, options, config). build_command returns a list whose
first element is the executable and remaining elements are its arguments.
Providers can share the adapter factory in lua/agents/providers/adapter.lua
and can be registered with require("agents.providers").register().
An adapter may set context_prefix when its CLI has stable file-mention syntax;
the default is an empty prefix.
Providers may optionally implement supports_suggestions(config) and
build_suggestion_request(request, config). Suggestion process execution and
ghost-text rendering remain provider-neutral.
